# Мої витрати — Telegram Mini App

Застосунок складається з одного файлу `index.html`. Дані зберігаються в Telegram CloudStorage
(окремо для кожного користувача), тому сервер і база даних не потрібні.

Витрати можна вносити в гривнях, доларах, євро, чеських кронах і злотих. Підсумки перераховуються
в обрану валюту за поточним офіційним курсом НБУ.

## Що вміє

- **Головна** — витрати, доходи й залишок за місяць, бюджет із підказкою «скільки можна на день», календар, останні записи.
- **Кнопка «+»** — витрата або дохід; голосове введення (українська, російська, англійська); сканування чека;
  «🔁 Щомісяця» для регулярних платежів; «👥 Розділити» для спільних витрат.
- **Історія** — пошук за весь час, фільтри за типом і категорією; натисни на запис, щоб змінити чи видалити його.
- **Статистика** — порівняння з минулим місяцем, графік по днях, категорії з лімітами, останні 6 місяців.
- **Друзі** — хто кому скільки винен, «Розрахувались», «Нагадати» (повідомлення в Telegram).
- **Налаштування** (⚙️) — мова, валюти, бюджет і ліміти, регулярні платежі, нагадування в Google Календар,
  експорт у CSV / Excel, теми й власна палітра.

Кнопка сканування в формі розуміє скриншоти банківських застосунків (оплата, переказ, надходження, список операцій)
і фото чеків: визначає суму, валюту, куди пішли гроші й категорію. На комп'ютері скриншот можна вставити Ctrl+V.
Сканування завантажує бібліотеку розпізнавання тексту (Tesseract.js, ~20 МБ) лише першого разу, коли ним користуються.

## Як запустити в Telegram

### 1. Викласти `index.html` в інтернет (потрібен HTTPS)

Найпростіше — через GitHub Pages:
1. Створи на github.com новий публічний репозиторій, наприклад `expenses`.
2. Натисни **Add file → Upload files** і завантаж `index.html`.
3. Відкрий **Settings → Pages**, у **Branch** вибери `main`, папку `/ (root)` і натисни **Save**.
4. Через 1–2 хвилини сайт з'явиться за адресою `https://<твій-логін>.github.io/expenses/`.

### 2. Створити бота й прив'язати до нього застосунок

1. Відкрий у Telegram [@BotFather](https://t.me/BotFather) і надішли команду `/newbot`.
   Вигадай ім'я та username, що закінчується на `bot`.
2. Надішли `/mybots`, вибери свого бота й натисни **Bot Settings → Menu Button → Configure menu button**.
3. Встав посилання з першого кроку, а потім введи назву кнопки, наприклад `Витрати`.

Тепер у чаті з ботом ліворуч від поля вводу з'явиться кнопка, яка відкриває застосунок.

> Дані прив'язані до конкретного бота. Якщо створити нового бота, витрати зі старого в ньому не з'являться.

## Перевірка на комп'ютері

```
python -m http.server 8765
```

Потім відкрий http://localhost:8765. Поза Telegram дані зберігаються лише в localStorage браузера.
